# Widget umbrella specification — Fiber

Status: definitive information contract, variants pending  
Umbrella ID: `nutrition.fiber`

Question: **How much fibre is logged, and how does it compare with the
applicable reference or personal target?**

Essential `1×1`: logged amount, period, coverage and reference identity when
used.

Aggregate only known fibre values. Unknown foods/fields reduce completeness.
Reference comparison is population/purpose aware and versioned.

Variants: amount/progress, food contribution and trend. Initial sizes:
`1×1`, `1×2`, `2×1`, `2×2`.

Not a digestive-health diagnosis. Detail exposes contributing foods, reference,
coverage and history.
