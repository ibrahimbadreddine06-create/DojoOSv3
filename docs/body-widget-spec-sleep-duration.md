# Widget umbrella specification — Sleep Duration

Status: definitive information contract  
Umbrella ID: `rest.sleep_duration`

Question: **How much sleep was recorded for the selected night/period?**

Essential `1×1`: duration, selected interval, main-sleep/nap inclusion and data
state. Time asleep and time in bed remain distinct.

Variants: duration/goal, period trend, nightly distribution. Initial sizes:
`1×1`, `1×2`, `2×1`, `2×2`.

References are age/context applicable and never become a personal diagnosis.
Detail shows sessions, inclusion rules, coverage and history.
