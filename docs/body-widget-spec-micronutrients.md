# Widget umbrella specification — Micronutrients

Status: advanced information contract, variants pending  
Umbrella ID: `nutrition.micronutrients`

Question: **Which selected vitamins/minerals are sufficiently logged, and how
do they compare with applicable references?**

Essential `1×1`: selected nutrient coverage/comparison plus log completeness.

Each nutrient retains unit, food-database provenance, reference type,
population applicability and unknown values. The widget is configurable; it
does not create child umbrellas for every nutrient.

Variants: selected-nutrient focus, compact adequacy field, period trend.
Initial sizes: `1×1`, `1×2`, `2×1`, `2×2`.

No deficiency diagnosis and no red/green judgment without readable values.
Detail exposes inputs, references, foods, unknowns and history.
