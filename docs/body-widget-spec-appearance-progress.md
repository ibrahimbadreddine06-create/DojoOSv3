# Widget umbrella specification — Appearance Progress

Status: optional sensitive user-defined contract  
Umbrella ID: `hygiene.appearance_progress`

Question: **How has my chosen non-skin appearance observation changed across
comparable entries?**

Essential `1×1`: chosen observation, latest comparable result and date/quality.
The user defines the target and meaning.

Variants: visual comparison, measurement trend, journal sequence. Initial
sizes: `1×1`, `1×2`, `2×1`, `2×2`.

No imposed ideal, ranking or automated attractiveness judgment.
