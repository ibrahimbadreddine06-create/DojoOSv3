# Widget umbrella specification — Cycle

Status: opt-in sensitive, method-dependent contract  
Umbrella ID: `hygiene.cycle`

Question: **What cycle status/history does the selected method support?**

Essential `1×1`: cycle day/status, source/method, uncertainty and privacy state.
Inputs may include period events, symptoms and eligible temperature/test data.

Provider predictions remain provider-owned; Body projections require a
validated versioned method. Variants/sizes depend on selected mode, beginning
with `1×1`, `1×2`, `2×1`, `2×2`.

Not contraception or diagnosis without an explicitly regulated mode.
