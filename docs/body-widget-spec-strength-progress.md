# Widget umbrella specification — Strength Progress

Status: definitive information contract; method-specific variants pending  
Updated: 2026-07-25  
Umbrella ID: `activity.strength_progress`

## Identity

Question: **How is performance changing for the selected exercise or movement?**

Essential `1×1`: exercise identity, current meaningful performance result,
comparison/history and logging state.

## Data and methods

Inputs may include sets, reps, external load, bodyweight, assistance, RIR/RPE,
range/tempo and completion. Exercise identity/version is stable.

Volume, best set, personal record and e1RM are different methods. They may power
different variants when named and justified; no universal muscular score is
invented.

## Manual/wearable behavior

Manual execution data is first-class. Wearable data may enrich a session but
cannot replace sets/reps/load it did not actually observe.

## Variant directions

- selected-exercise progression;
- personal-record progression;
- sets/reps/load composition.

Initial sizes: `1×1`, `1×2`, `2×1`, `2×2`, `3×1`.

Detail includes exercise history, set-level records, method explanation,
program context, corrections and source.
