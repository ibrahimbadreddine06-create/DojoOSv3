# Widget umbrella specification — Physiological Stress

Status: conditional provider-result contract  
Umbrella ID: `rest.physiological_stress`

Question: **What physiological activation/stress did the selected provider
estimate across the period?**

Essential `1×1`: provider result/distribution, period, source and coverage.

Unlike provider models remain separate. Variants: current result, daily
timeline, intensity distribution. Initial sizes: `1×1`, `1×2`, `2×1`, `2×2`.

Not equivalent to perceived stress and not a mental-health diagnosis.
