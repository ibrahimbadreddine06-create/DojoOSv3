# Widget umbrella specification — Body Timeline

Status: definitive cross-domain observation contract  
Umbrella ID: `hub.body_timeline`

Question: **Which Body-relevant events occurred or are explicitly linked
today?**

Essential `1×1`: nearest/latest resolved event and temporal context.

Events retain their original identity/source: sleep, activity, intake,
measurement, routine and explicitly linked planner item. The timeline does not
become a generic planner.

Variants: nearest-event, chronological list, day strip. Initial sizes:
`1×1`, `1×2`, `2×1`, `2×2`, `3×1`.
