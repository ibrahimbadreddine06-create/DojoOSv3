# Gentler Streak — targeted competitor evidence pass

Status: Tier B targeted pass  
Updated: 2026-07-25

## Evidence boundary

This pass uses Gentler Streak's current first-party documentation. It records
observable product logic; it does not infer an undisclosed formula.

## Distinctive product architecture

- Activity Path is the central product: an optimal green band over time with a
  dotted actual-activity line.
- Position within the band translates load into a readable state: room for
  activity, balance, or proximity to excessive load.
- Daily interpretation copy contextualizes the visual rather than replacing it.
- Wellness cards connect sleep, steps, vitals and menstrual-cycle context to
  readiness.
- Daily non-workout steps can optionally be included in Activity Path.

## Visual and interaction grammar

- The key visualization shows a target *range*, not merely a target line or
  score.
- Small widgets preserve the path state plus a short message; larger widgets
  expose more of the path and guidance.
- Single-metric widgets can combine current value, range status and a trend.
- A suggested-action widget turns interpretation into an executable workout
  recommendation.

## Product lessons, not widget decisions

- Showing actual load inside a changing acceptable envelope can communicate
  both under- and over-training without inventing a universal score.
- A status sentence is useful when it interprets a real visual state.
- Optional inclusion of daily steps shows that product semantics must expose
  what counts toward a metric.

## Remaining evidence tasks

- Establish the documented Activity Path calculation and time horizons.
- Capture current screen and widget variants directly.
- Validate accessibility and behavior for incomplete Apple Health data.
