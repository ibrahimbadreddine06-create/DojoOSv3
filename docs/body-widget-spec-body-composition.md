# Widget umbrella specification — Body Composition

Status: conditional provider-result contract  
Umbrella ID: `hub.body_composition`

Question: **What composition estimates did the selected method produce, and
how are same-method values changing?**

Essential `1×1`: selected estimate, method/device, date and uncertainty.

Fat, lean, muscle, water and bone values preserve provider semantics. Consumer
BIA estimates and unlike devices are not silently interchangeable.

Variants: selected component, composition field, same-method trend. Initial
sizes: `1×1`, `1×2`, `2×1`, `2×2`.
