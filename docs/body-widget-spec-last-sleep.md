# Widget umbrella specification — Last Sleep

Status: definitive information contract, variants pending  
Umbrella ID: `rest.last_sleep`

## Operational contract

Manual record/edit is an integral fallback with manual provenance. A sleep
commitment may be linked for comparison, but planned timing/hours never become
fields pretending to belong to the observed sleep session.

Question: **What happened during my latest resolved main sleep?**

Essential `1×1`: total sleep, timing/date, source/freshness and concise session
state. Resolve overlapping providers before selection; naps remain separately
identified.

Variants: duration-first summary, night composition, contributor summary.
Initial sizes: `1×1`, `1×2`, `2×1`, `2×2`.

Detail opens the exact sleep session with stages/signals when eligible,
coverage, source, corrections and limitations.
