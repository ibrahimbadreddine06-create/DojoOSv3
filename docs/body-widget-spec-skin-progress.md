# Widget umbrella specification — Skin Progress

Status: optional sensitive observation contract  
Umbrella ID: `hygiene.skin_progress`

Question: **How has my selected skin observation changed across comparable
entries?**

Essential `1×1`: latest comparable observation, date, selected concern/area and
capture-quality state.

Use standardized photos/user observations with capture conditions; variants:
before/after, timeline, observation trend. Initial sizes: `1×1`, `1×2`,
`2×1`, `2×2`.

No diagnosis or beauty score. Images require explicit privacy, deletion and
export behavior.
