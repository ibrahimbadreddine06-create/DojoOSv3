# Widget umbrella specification — Skin Temperature

Status: conditional provider-observation contract  
Umbrella ID: `rest.skin_temperature`

Question: **What skin-temperature value/deviation did the source record, and
how does it compare with its own baseline?**

Essential `1×1`: absolute value or deviation (never confused), period, source
and state.

Variants: deviation-first, baseline trend, nightly range. Initial sizes:
`1×1`, `1×2`, `2×1`, `2×2`.

Skin/wrist temperature is not core temperature or fever detection.
